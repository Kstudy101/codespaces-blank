개선·백업용으로 유지하되, merge 로 데일리 문법 퀴즈를 덮어쓰지 않는다.

## 0. 진단 — 왜 쉬운가

현행 `gen-review-quiz.mjs` 는 그날까지 나온 한국어를 **통째로 풀**에 넣고
결정적 셔플로 오답 3개를 뽑는다. 품사·길·의미가 제각각이라, 보기만 보면
정답이 튀어 나온다.

| 현행 예 (중급 review) | 문제 |
|---|---|
| 「伝える」→ `했어요` / `온다고` / **전하다** / `민수가` | 활용형·이름·동사원형이 섞임 → 원형만 고르면 됨 |
| 「忙しい」→ `민수가` / **바쁘다** / `온다고` / `숙제` | 형용사 자리에 인명·인용형 |
| 「責任」→ `친구` / **책임** / `날씨` / `도와주다` | 명사 질문에 동사·일상명사 |

또한 이 review JSON 은 **회화 리프레시 이전 어휘** 기준일 가능성이 크다.
초·중·상 `vocab_3` 가 바뀌었으므로, 난이도 개편과 함께 **재생성**이 필요하다.

---

## 1. 목표 난이도

- 보기 4개(또는 3개)가 **같은 품사·비슷한 길이**
- 오답은 「헷갈릴 법한 이웃」:
  1. **동의·근의** (전하다 / 알리다 / 전달하다)
  2. **한자어 형제** (소식 / 소문 / 소식통)
  3. **활용·원형 함정** (먹다 / 먹어요 — 질문은 원형을 요구)
  4. **조사·형태 근처** (취미 / 취미가 — 표제어만 정답)
- 여전히 **그 날까지 나온 말만** (merge-quiz `taughtBy` 규칙 유지)
- 정답이 두 개가 되면 안 됨 (동의어를 오답에 넣을 때 질문 뜻을 좁힌다)

## 2. 생성 규칙 초안 (gen-review-quiz 개편)

정답 후보: 그날 `vocab_3` 중 1어 (현행과 동일, 실단어 우선).

오답 후보 점수 (높을수록 채택):

| 가산 | 조건 |
|---|---|
| +3 | 정답과 **같은 pos** (名詞/動詞/形容詞) |
| +2 | 어간 2글자 이상 공유 또는 같은 한자어 어근 느낌 (`소식`↔`소문`) |
| +2 | 같은 끝소리 패턴 (`-하다` 동사끼리, `-다` 형용사끼리) |
| +1 | 글자 수 차이 ≤ 2 |
| −5 | 인명·조사 조각·인용 잔해 (`민수가`, `온다고`, `이/가`) — **풀에서 제외** |
| −3 | 정답의 활용형만 다른 것 (`전해요` vs `전하다`) — 질문 유형에 따라 허용/금지 |

질문 유형을 둘로 나눌 수 있음 (옵션):

- **A (기본)**: `「{일본어 뜻}」の韓国語は？` — 원형·표제어. 활용형은 오답 금지(또는 함정 1개만).
- **B (심화, 일부 날)**: `「{일본어}」に一番近い語は？` — 근의어 3개 + 정답.

후보가 부족하면: 같은 pos 전체 풀 → 그래도 부족하면 현행처럼 넓히되
**제외 목록(−5)** 은 유지.

## 3. 초안 샘플 (Before → After)

아래는 **문면 초안**. 구현·merge 전. 중급 review 위주 (지금 보고 계신 파일).

### 중급 Day 1 — 「伝える」

**Before:** `했어요` / `온다고` / **전하다** / `민수가`  
**After:**

```json
{
  "question": "「伝える」の韓国語は？",
  "choices": ["알리다", "전하다", "말하다", "전달하다"],
  "answer": 1
}
```

※ `전달하다` 가 그날까지 미출이면 `알리다`/`전하다`/`듣다`/`쓰다` 등으로 대체.
`taughtBy` 통과가 우선.

## 4. 데일리 문법 퀴즈(레슨 말미 ❓) 는?

신양식 `autoQuiz` 는 오답이 **직전 1〜7일의 fb(문법 형태)** 라,
이미 「다른 문법」끼리 붙는다. 쉬운 날은 일본어 뜻풀이가 한눈에 갈라질 때.

| 옵션 | 내용 |
|---|---|
| **R만 (추천 1차)** | review JSON + gen-review-quiz 만 개편. 데일리는 유지 |
| **R+D** | 데일리도 「혼동 문법 쌍」 손퀴즈를 늘림 (안/못, -아서/-니까, -려고/-러 등) |
| **D만** | 데일리만 — 지금 열어 두신 파일과는 결이 다름 |

대표님이 보신 「너무 쉬움」이 review 쪽이면 **R만**으로 충분하다.

## 8. 오답 피드백 설계 (추가)

현행도 `❌ … 正解は ② xxx でした` 는 있다. 확정안은 **선택지와 정답을 나란히** 보여
「고른 보기 vs 정답」이 한눈에 오게 한다.

```
❌ ざんねん…
あなたの答え: ① 알리다
正解: ② 전하다
ひとこと: 「伝える」

今日もお疲れ様でした。
言語は毎日の繰り返しです！
また明日お会いしましょう。오늘도 화이팅！
```

- `quiz.explain` 이 있으면 ひとこと로 사용 (손퀴즈·혼동쌍)
- 없으면 질문文의 `「…」` 를 힌트로 추출
- review / 절목(`action=quiz`) 공통 함수
- data 에 answer 를 싣지 않는 규칙은 유지 (서버 채점)

### 8-b. 정오답 공통 맺음말（2026-08-09 대표 승인 C）

採点のあと（⭕／❌ どちらも）同じ 3 行で閉じる。
正解専用だった `今夜また会いましょう！` 系はこれに置き換え。
