## 0. 현행 진단 (짧게)

| 관찰 | 수치·예시 |
|---|---|
| 화자 편중 | `친구` 약 156회 / `{NAME_JP}` 103 / `동료` 26 / 그 외(점원·손님 등) 소수 |
| 메타 설명형 대사 | 「핵심이에요」「예를 들면」「한 줄」류가 자주 등장 — 회화라기보다 수업 |
| 장면 반복 | 취미·커피·주말·운동·회사·날씨 축이 많음 |
| 단어 | 장면과 느슨히 연결되거나, 추상 형용사(`정중하다`·`격식있다`)가 앞쪽에 모임 |

문법(`gp`)·진도 순서는 **배달 중이라 변경 불가**(파일 머리말·plan-newformat §5-B).

## 1. 고정 제약 (구현 시에도 절대)

1. **`gp` 순서·일수 매핑 불변** (1〜101).
2. 신양식 스키마: `tip` 3행(形/使/落·일본어) / `dlg` 3행 / 마지막 `kr`에 `fb` 포함 / `v6` 名詞2·形容詞2·動詞2 / `bridge` 고유·운세 단정 금지.
3. tip의 使·落은 일본어(예시 형태만 한국어). 설명문을 한국어로 되돌리지 않음.
4. 관문: `node server/content/_build-beginner.mjs` → content-check 전수 통과.
5. 시드 타이밍: JST 18시 이후 업로드·시드 금지(STATUS §0-㉑).

## 2. 리프레시 방향 (제안)

### 2-1. 「수업 대사」→「장면 대사」

- 마지막 줄에 문법 이름을 설명하지 않는다. **그날의 `fb`가 자연스럽게 나오는 한 컷**만.
- tip이 규칙을 맡고, 회화는 규칙을 「쓰는」 역할.

### 2-2. 화자 로테이션 (예시 캐스트)

| 화자 | 쓰는 구간·분위기 |
|---|---|
| 친구 | 일상·카톡·약속 (줄이되 매일은 아님) |
| 동료 / 선배 | 회사·회의·점심 |
| 점원 / 직원 | 편의점·카페·옷가게·역무 |
| 가이드 / 호스트 | 여행·게스트하우스 |
| 옆자리 / 손님 | 지하철·식당·분실물 |
| 동생 / 룸메 | 집·요리·심부름 |
| 트레이너 / 알바 | 헬스·카페 |
| DJ / MC | 노래방·이벤트 (드물게) |

### 2-3. 장면 팔레트 (101일을 대략 순환)

편의점 · 지하철 · 배달앱 · 노래방 · PC방/보드게임 · 한식당 주문 · 시장 ·
한강/공원 · 게스트하우스 · 공항 · 언어교환 · K-드라마 수다 · 헬스장 ·
우체국/편의점 택배 · 비 오는 날 우산 · 생일 케이크 · 카톡 오해 ·
면접 대기실 · 도서관 · 캠핑 · 김치 담그기 · 101일 완주

같은 장면을 3일 연속으로 쓰지 않는다. 문법 난이도와 장면을 억지로 맞추지 말고,
**그 문법이 가장 자연스럽게 나오는 장면**을 고른다.

### 2-4. 미니 시리즈 (선택안)

승인 시 일부만 연속 이야기로 묶을 수 있음.

| 시리즈 | 일수 예 | 한 줄 줄거리 |
|---|---|---|
| A. 서울 3박 | 11〜15 근처 | 도착→약속→시장→선물→「이것만」 |
| B. 회사 첫 주 | 16〜20 | 헤요체→합쇼체→어제 야근→의지→주말 계획 |
| C. 배달·요리 | 48〜50 | 국수 고민→시착→「먹어 본 적」 |

시리즈를 싫어하면 **하루 완결 에피소드만**으로도 충분.

## 3. 초안 샘플 (Before → After)

아래는 **구현용이 아닌 문면 초안**. `gp`·대략의 `fb`는 현행을 유지하는 쪽을 기본으로 하되,
장면이 바뀌면 `fb` 문자열·vocab·bridge·quiz는 같이 갈아탄다(승인 후).

### Day 1 — `-입니다`　장면: 언어교환 첫날 (현행: 교실식 자기소개)

**Before (요지):** 이름 묻기 → 「{NAME}입니다」→「한 줄. 저는 학생입니다」

**After 초안:**

```
dlg: [
  { who: "호스트", kr: "처음 뵙겠습니다. 오늘 언어교환 맞으시죠?",
    ja: "初めまして。今日の言語交換でいらっしゃいますね？" },
  { who: "{NAME_JP}", kr: "네, {NAME}입니다. 잘 부탁드립니다.",
    ja: "はい、{NAME_JP}です。よろしくお願いします。" },
  { who: "호스트", kr: "저도 김민수입니다. 편히 말씀하세요.",
    ja: "私もキム・ミンスです。気楽に話してください。" }
]
fb: "입니다"
v6: [["언어교환","言語交換","名詞"],["처음","初めて","名詞"],
     ["설레다","胸が躍る","形容詞"],["긴장되다","緊張する","形容詞"],
     ["만나다","会う","動詞"],["부탁하다","お願いする","動詞"]]
bridge: ["오늘 만난 사람에게 「~입니다」로 한 줄.",
         "今日会った人に「~です」で一行。"]
quiz: 자기소개에 「입니다」가 들어가는 보기 (현행 취지 유지)
```

### Day 5 — `-을/를`　장면: 편의점 야식 (현행: 김밥·책)

```
dlg: [
  { who: "점원", kr: "봉투 드릴까요?", ja: "袋をお付けしますか？" },
  { who: "{NAME_JP}", kr: "네. 그리고 이거 데워 주세요.",
    ja: "はい。あと、これ温めてください。" },
  { who: "점원", kr: "삼각김밥을 데워드릴게요. 잠시만요.",
    ja: "三角キンパを温めますね。少々お待ちください。" }
]
fb: "삼각김밥을"   ※ 또는 「김밥을」로 짧게
v6: [["삼각김밥","三角キンパ","名詞"],["봉투","袋","名詞"],
     ["뜨겁다","熱い","形容詞"],["배고프다","お腹が空く","形容詞"],
     ["데우다","温める","動詞"],["사다","買う","動詞"]]
```

## 4. 작업 범위 옵션 (대표 선택)

| 옵션 | 범위 | 공수 감 | 비고 |
|---|---|---|---|
| **A** | 회화(`dlg`)만 · `fb` 유지 가능한 날 우선 | 소 | 장면만 바꿔도 체감↑. tip·vocab 거의 유지 |
| **B (추천)** | 회화 + vocab + bridge · `fb`는 장면 맞게 갱신 | 중 | tip·`gp` 고정. 퀴즈는 autoQuiz 재생성 + 손퀴즈 절목만 점검 |
| **C** | B + tip 문면도 「한 줄 더 날카롭게」 | 대 | 규칙 내용은 동일, 표현만. tip 일본어 유지 |

**제외(scope 밖) — 기본값**

- `gp` 순서·일수 교체
- 중급·상급 동시 개정
- 렌더러·스키마·관문 규칙 변경
- 시드/배포 자동화 변경
