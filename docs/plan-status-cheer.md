# plan-status-cheer — ［何日目？］에 한국어 응원 한 줄

최종 갱신: 2026-08-09  
상태: **승인됨 · 구현**

---

## 1. 목적

`今日までN/101です。` 만으로는 쌀쌀맞다는 피드백.  
진도 숫자는 유지하고, 한국어 격려 + 이모지 + 이름 호명을 붙인다.

대표 최종 승인 문면（2026-08-09）:

```
今日まで3/101です。🇰🇷💕

화이팅! 오늘도 한 걸음 💪✨
[name]님 응원합니다^^
```

결정: `name_kr` / 없을 때 `응원합니다^^` / `님` + 한 칸.

---

## 2. 완성 예시

```
今日まで3/101です。🇰🇷💕

화이팅! 오늘도 한 걸음 💪✨
다나카님 응원합니다^^
```

이름이 아직 없을 때:

```
今日まで0/101です。🇰🇷💕

화이팅! 오늘도 한 걸음 💪✨
응원합니다^^
```

## 3. 접근

| 항목 | 결정（초안） | 근거 |
|---|---|---|
| 변경 위치 | `statusMessage` 한곳 | 텍스트「進み具合」도 이미 여기를 호출 |
| 분자/분모 | 현행 유지 `current_day` / `TOTAL_DAYS` | 직전 합의 |
| `[name]` | **`user.name_kr`**（없으면 이름 생략） | 한국어 응원 문장과 톤이 맞음. 예문 주어도 한글 이름 |
| 공백 | `다나카응원합니다^^`（이름과 붙여 씀） | 대표 스케치 그대로 |
| 미수강 | 현행「まだ受講が…」유지. 응원 블록 없음 | 진도가 없을 때 격려는 어색 |
| 코스 전환 QR | 현행 유지. 응원 아래에 빈 줄 + 전환 안내 | 기능 회귀 방지 |

### 이름 대안（대표 선택）

| 안 | 값 | 예 |
|---|---|---|
| **A（권장）** | `name_kr` | `다나카응원합니다^^` |
| B | `name_reading`（가나） | `たなか응원합니다^^` |
| C | `name_kanji` | `田中응원합니다^^` |
| D | 읽기 우선 폴백 `name_kr \|\| name_reading \|\| name_kanji` | 빈 칸 최소화 |

초안 기본값은 **A**. 바꾸면 아래 스니펫의 `cheerName` 한 줄만 고치면 됨.

## 4. 코드 스니펫（예정）

`server/lib/handlers/checkout.mjs` — `statusMessage` 반환부:

```js
const active = owned.find((e) => e.track === user.active_track) || owned[0];
const dayLine = `今日まで${active.currentDay}/${TOTAL_DAYS}です。`;
const cheerName = String(user.name_kr || "").trim();
const cheer = [
  "화이팅! 오늘도 한 걸음 💪✨",
  cheerName ? `${cheerName}응원합니다^^` : "응원합니다^^"
];

return {
  type: "text",
  text: [
    dayLine,
    "",
    ...cheer,
    ...(switchable.length
      ? ["", "残っているコースへ切り替えられます（進みはそのままです）。"]
      : [])
  ].join("\n"),
  // quickReply は現行どおり
};
```

`message.mjs` — **변경 없음**（이미 `statusMessage` 위임）.
