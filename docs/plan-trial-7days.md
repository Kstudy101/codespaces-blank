## §2 upsell 타이밍 — `TRIAL_DAYS - 1` 로 일반화

지금은 **「2」가 4곳에 독립으로 박혀 있습니다.**

| 파일 | 지금 | 뒤 |
|---|---|---|
| `server/db/push-evening.mjs:118` | `Number(full.current_day) !== 2` | `!== TRIAL_UPSELL_DAY` |
| `server/db/push-evening.mjs:172` | `const upsell = day === 2 ? …` | `day === TRIAL_UPSELL_DAY` |
| `server/db/push-evening.mjs` (logSent) | `dayNumber: 2` | `dayNumber: TRIAL_UPSELL_DAY` |
| `server/lib/handlers/checkout.mjs:147·149` | 문면의 「明日が最後」·「2 日目」 | 아래 |

### §2-1 상수는 어디에 두는가

**`billing.mjs` 의 `TRIAL_DAYS` 옆으로.**

```js
export const TRIAL_DAYS = 7;

/* 체험 종료 전날 저녁에 1 번 권한다. 「2」를 push-evening 과 문면에
   따로 쓰면, 체험 일수를 바꾼 날 한쪽만 낡는다 ── 실제로 3→7 에서
   그 형태가 4 곳 나왔다. */
export const TRIAL_UPSELL_DAY = TRIAL_DAYS - 1;
```

**`push-evening` 안에서 `TRIAL_DAYS - 1` 을 다시 계산하지 마십시오** — 그것이
두 번째 출처입니다.

### §2-2 문면 — 「2 日目」를 숫자로 만들면 안 됩니다

`trialUpsellNotice` 는 지금 track 만 받습니다. 진행 일수를 인수로 받게 하십시오.

```js
export function trialUpsellNotice(track, { canBuy = false, currentDay = TRIAL_UPSELL_DAY } = {}) {
  const head = [
    `無料でお試しいただける ${TRIAL_DAYS} 日分のうち、明日が最後の 1 日です。`,
    "",
    `${l.ja}（${l.kr}）は ${currentDay} 日目まで進みました。`,
    ""
  ];
```

「明日が最後の 1 日です」는 `TRIAL_UPSELL_DAY = TRIAL_DAYS - 1` 인 한 **항상 참**이므로
그대로 둡니다. 여기를 계산식으로 바꾸면 상수의 문면이 다시 갈립니다.

**호출 측은 DB 의 실제 `current_day` 를 넘깁니다** — 판정과 표시가 어긋날 수 있다면
그건 문면이 숨길 일이 아닙니다.

## §3 ★ 가장 중요 ★ 기존 체험자가 매일 경고로 뜹니다

### §3-1 무엇이 일어나는가

`billing.mjs:200` 에 **상수가 SQL 문자열에 박혀 있었습니다.**

```js
const T = Number(TRIAL_DAYS);
const EXPECTED = `COALESCE(p.total, 0) + IF(s.trial_track = e.track, ${T}, 0)`;
```

`findEntitlementDrift` 는 `days_entitled <> EXPECTED` 인 사람을 전부 반환하고,
**`maintain` 이 매일 04:00 에 이것을 돌립니다.**

`TRIAL_DAYS` 를 7 로 바꾸는 순간:

| 사람 | `days_entitled` | 새 `EXPECTED` | drift |
|---|---|---|---|
| 3일 체험만 쓴 기존 이용자 | 3 | **7** | **−4** |
| 3일 체험 + 14일 구매 | 17 | **21** | **−4** |

**기존 체험자 전원이 매일 경고에 오릅니다.** 이 경고는 「돈은 냈는데 일수가 모자란
사람」을 잡으려고 만든 것이라 — 오탐이 상시화되면 **진짜 미지급을 읽고 넘기게 됩니다.**

### §3-2 해결 — 과거 행이 그때의 값을 스스로 들게 합니다

**상수가 시간에 따라 바뀌면, 그 상수로 만들어진 과거 행은 자기 값을 가져야 합니다.**

`server/db/migrations/007-trial-days.sql` 신설 + `EXPECTED` 를 열 기반으로:

```js
const EXPECTED =
  `COALESCE(p.total, 0) + IF(s.trial_track = e.track, COALESCE(s.trial_days, 0), 0)`;
```

**`DEFAULT 3` 을 붙이지 마십시오.** 기본값이 있으면 `startTrial` 이 열을 빼먹어도 3 이
조용히 들어가고, 7일 지급인데 장부는 3 인 상태가 **아무 신호 없이** 생깁니다.
NULL 허용이면 빼먹은 순간 drift 로 즉시 드러납니다.

이 변경은 7일 전환과 무관하게 **그 자체로 개선**입니다.

## §4 파생 영향 — 코드 밖

### §4-1 LINE 배신 통수가 **2.3배**

| | 아침 | 저녁 | 합계 |
|---|---|---|---|
| 3일 | 3 | 3 | **6통** |
| 7일 | 7 | 7 | **14통** |

upsell 은 저녁 배열에 합쳐 1회 호출로 나가므로 추가 과금 0 입니다.

**전환하지 않는 사람에게 쓰는 통수가 2.3배가 됩니다.** 「월 신규 체험자 × 14통」이
무료 통수 안에 들어가는지 계산해 두십시오. **코드로 막을 수 있는 것이 아니라
요금제 문제입니다.**

### §4-2 재고 소모

체험자 1인당 원고 노출이 3일 → 7일. 101일 원고에서 6.9% 이고 재사용 자산이므로
실질 손실은 아닙니다.

## §5 대표 판정이 필요한 2건

### §5-1 (다) 체험 중 기한 예고 — **원래 근거가 소멸합니다**

`push-daily.mjs` 주석이 억제 이유를 이렇게 적고 있었습니다.

> 体験 3 日は remaining 3→2 が初日に来るので、始めた直後の 1 通に 2 日しか付いてしまう

`EXPIRING_AT = 2` 이므로 **7일 체험에서는 5일차 아침**에 걸립니다 — 「시작 직후」가
아닙니다. **억제의 근거가 없어집니다.**

| 안 | 내용 |
|---|---|
| **(A) 유지 — 권고** | 판정이 `hasPurchases`(구매 0)라 코드 변경 **0줄**. 권유는 6일차 저녁 1회로 충분하고, 통수도 절약 |
| (B) 해제 | 5일차 아침 예고 + 6일차 저녁 권유 = 2회. 통수 +1, 「촉박함」으로 읽힐 위험 |

**(A) 를 권합니다.** 다만 주석의 근거 문장은 반드시 갱신하십시오 — 근거가 죽은 채로
남으면 다음 사람이 그것을 믿고 판단합니다.

### §5-2 (나) `7days ¥980` 패키지 — 판단이 갈립니다

체험 7일 = 최저가 패키지 `7days ¥980` 과 **일수가 같아집니다.**

| 읽기 | 근거 |
|---|---|
| **해롭다** | 체험을 끝낸 사람이 가격표 첫 줄에 「7日 980円」. 방금 공짜로 받은 것과 같은 양에 값이 붙습니다 |
| **이롭다** | 7일을 체감한 사람에게 「이 경험 7일치가 980원」은 **가장 이해하기 쉬운 값**입니다 |

| 안 | 조치 | 비고 |
|---|---|---|
| **(A) 그대로** | 0줄 | 전환 데이터를 본 뒤 판단. **되돌리기 가장 쉬움** |
| (B) 7days 판매 중지 | `PACKAGES` 에서 제외 | 최소구매가 ¥1,680 으로. ARPPU↑ · 진입장벽↑ |
| (C) 체험 5일 | `TRIAL_DAYS = 5` | 충돌 회피. 「일주일 체험」이라는 마케팅 문구를 잃습니다 |

**데이터가 없으므로 단정하지 않겠습니다.** **(A) 로 시작해 첫 코호트의 전환을 보고
결정**하는 쪽을 권합니다.

| 전환 설득 재료 | 거의 없음 | 「続けたい」의 근거가 생김 |
| LINE 통수 | 기준 | **2.3배** (§4-1) |
| 최저가 패키지와의 관계 | 문제 없음 | 일수가 같아짐 (§5-2) |
| 되돌리기 | — | `TRIAL_DAYS` 만 되돌리면 됨. **`trial_days` 열 덕에 과거 계약이 안 흔들림** |

마지막 줄이 §3-2 를 하는 진짜 이유입니다. 열이 들어가면 **7일이 실패했을 때 5일로
되돌리는 것이 완전히 조작**이 됩니다.
