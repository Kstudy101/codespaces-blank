근거: 대표 — `正解です！` 가 딱딱함. 저녁 복습이 있으니 그때를 기다리며 공부하자는 톤.

## 0. 현행

`server/lib/render.mjs` → `formatQuizReply`（데일리・복습・절목 공통）

| 결과 | 문면 |
|---|---|
| 正解（일반） | `⭕ 正解です！🎉` |
| 正解（절목） | `⭕ 正解です！🎉\n第N学期の節目クイズ、合格です！` |
| 不正解 | `❌ ざんねん…` + 선택/正解 + ひとこと |

## 1. 방향

1행: 정답 축하（현행 유지 또는 살짝 부드럽게）  
2행: **저녁 6시 복습**을 기다리자는 말  
3행: 짧은 응원（한국어 가능）

데일리 ❓ / 복습 퀴즈 / 절목 퀴즈 **같은 꼬리**를 쓸지, 절목만 합격 멘트를 남길지 선택.

## 3. 절목 퀴즈（合格）와의 겹침

현행 절목은 2행째에 `第N学期の節目クイズ、合格です！`.

| 안 | 내용 |
|---|---|
| **X（권장）** | 절목도 **같은 응원 꼬리**. 합격 멘트는 1행 옆 또는 그 다음 한 줄만 유지 |
| Y | 절목은 합격 멘트만, 데일리・복습에만 저녁 안내 |

**X 예시（절목）**

```
⭕ 正解です！🎉
第2学期の節目クイズ、合格です！

夕方の復習もあるよ〜 それまで少し休憩してね☕
공부 열심히 해요! 화이팅 💪
```

  "공부 열심히 해요! 화이팅 💪"

if (passed) {

    return `⭕ 正解です！🎉\n第${checkpointSemester}学期の節目クイズ、合格です！${cheer}`;
