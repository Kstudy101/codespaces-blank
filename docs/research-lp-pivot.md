## 2. 지금 `index.html` 이 하는 일 (철회 대상)

- 타이틀·OG·히어로 전부 「名前からはじめるハングル勉強」
- 본문은 이름 입력 → 한글 표기·자모 분해·이름 한자 학습·사주성 진단
- LINE 배너는 히어로 **아래** 보조 유입 (`lin.ee/SKZtS5k`)
- `verify-kana` 가 **index.html 실물의 가나→한글 표**와 `server/lib/kana2hangul.mjs` 를 전수 대조

**함의:** index 를 「이름 도구」에서 떼면 `kana2hangul` 사본 정본이 사라진다.
LP 재작성 시 **가나표를 어디(숨긴 페이지·공용 JS·서버만)로 옮길지**를 계획에 넣어야 한다.
관문을 깨지 않고 표를 옮기는 설계는 [plan-lp-line-daily.md](plan-lp-line-daily.md) §9.

## 3. 카피가 맞춰야 할 **이미 돌아가는** 제품 사실

| 사실 | 출처 | LP에 쓸 말 |
|---|---|---|
| 앱 설치 없음 · LINE 친구추가만 | STATUS §0, webhook | 「アプリ不要。友だち追加だけ」 |
| 아침 07:00 / 저녁 18:00 JST | push-daily / push-evening | 「朝7時のレッスン＋夜6時のクイズ」 |
| 체험 일수 **7일 전환 중** (배포 대기) | plan-trial-7days | CTA·FAQ는 **7日無料**로 통일. 배포 전엔 라이브와 어긋날 수 있음 → STATUS §0-◆ |
| 주간 사이클(월~일) 설계 | plan-content-weekly (대표 확정·구현 전) | 커리큘럼 섹션은 이 설계와 **동일**. 아직 원고 미교체면 「미리보기」로 표기 |
| 판매 단위 = 1주일 패키지 | plan-content-weekly §2 | 최종 CTA에서 「無料1週 → 続けたい週だけ」톤 가능. **가격 숫자는 대표 몫** — LP에 ¥ 확정 금지 |
| 서비스명 표기 혼재 | contact만 「名前で学ぶ…」, 나머지 구명칭 | LP·특상법·privacy **같은 커밋에서** 통일 필요 (STATUS §0-☆-a) |

- 일본 거주 **20〜40대 여성**, K-POP / K드라마 애호, 독학 작심삼일 경험

- CTA 색: LINE 그린 (`#06C755` 계열) — 브랜드 인식용. 사이트 기존 `--accent` 와 충돌하면 **CTA만** LINE 그린

## 5. 페이지 추가·교체 시 반드시 손대는 4곳 (CLAUDE.md)

index 를 LP로 갈아끼워도 파일명이 `index.html` 이면 PUBLIC 배열은 유지.
다만 메타·스모크 문구가 바뀌면:

1. `build-site.sh` 의 `PUBLIC` (파일 추가 시)
2. `set-site-url.py` 의 `TARGETS`
3. `sitemap.xml`
4. `deploy.yml` 스모크

이름 도구를 **별 URL**로 남기면 위 4곳 + `verify-pages` / `verify-kana` 경로 갱신.
