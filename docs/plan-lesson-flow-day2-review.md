## 1. 목표 화면（Day2 예시）

### 1통 · 학습포인트（形 노출）

```
🔗 接続 (活用ルール)
パッチム無 → -예요／有 → -이에요

💡 学習ポイント
・形: パッチム無 → -예요／有 → -이에요
・使: 打ち解けた丁寧体。日常会話の基本
・落: 「학생이에요」「친구예요」。1日目の「-입니다」は改まった場面用
```

※ 形 문구는 tip `形` 행을 그대로 씀（接続과 동일 문장）. 원고 tip을 새로 쓰지 않음.

## 2. 접근

### A. 렌더러（#2 · #3）— 원고 불필요

`server/lib/render.mjs`

1. **学習ポイント**에 `・形:` 를 使·落과 같은 형식으로 추가  
   （接続 블록은 현행 유지 — 활용 규칙은 그대로 위에）
2. **単語**: 품사 헤더 다음 줄부터 단어 1개 = 1행

```js
// 学習ポイント（예정）
head.push("", "💡 学習ポイント",
  `・形: ${tip.form[0]}`, ...tip.form.slice(1),
  `・使: ${tip.use[0]}`, ...tip.use.slice(1),
  `・落: ${tip.fall[0]}`, ...tip.fall.slice(1));

// 単語（예정）
v.push(`【${pos}】`);
for (const w of ws) {
  n++;
  v.push(`${n}. ${w.kr}　${w.meaning}${note}`);
}
```

### B. 회화 3→4행（#1）— 원고 + 관문

| 층 | 변경 |
|---|---|
| `content-check.mjs` | `dia.length !== 3` → `!== 4` |
| `tools/verify-render.mjs` | 「정확히 3행」검사 → 4행 |
| `_build-{beginner,intermediate,advanced}.mjs` | 전일 `dlg` 4행으로 재집필 |
| JSON 재생성 · 시드 | 빌드 후 FTPS + `seed-content`（**JST 18시 전**） |

**집필 규칙（4행 드라마）**

| 행 | 역할 |
|---|---|
| 1 | 상대 개시（질문·제안） |
| 2 | 학습자 반응（장면） |
| 3 | 상대 이어가기（선택·확인） |
| 4 | 학습자 완결（답·결정）— **가능하면 `fb` 포함** |

- tip·`gp`·quiz·vocab 골격은 **유지**（이번 범위는 회화 행수·완결성）.
- vocab/bridge는 장면이 바뀌지 않는 한 그대로. 4행 때문에 장면이 어색해지면 그 날만 단어·bridge 미세 조정.
- 범위 제안: **초·중·상 101일 전량**（대표 문구「모든 회화」）. 부담이 크면 **초급 우선 → 중·상** 2단도 가능.
